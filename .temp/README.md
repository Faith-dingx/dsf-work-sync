# .temp/ 测试临时文件固定目录（工作区内）

## 规矩（用户约定 2026-08-19）
1. **测试/调试产生的临时文件一律放这里**，绝不写系统分区（/tmp、/var 等）。
2. **位置固定**：本目录 + archive/ 子目录，便于查询。
3. **测试结束立刻整理**：
   - 有保留价值 → 归档到 `.temp/archive/`（改名带日期，如 `test-xxx-20260819.json`）
   - 无价值 → 立即删除，不留垃圾。
4. 长期有价值的产出 → 移入工作区正式文档（docs/ 等），不留 .temp。

## 结构
- `.temp/`        进行中测试的临时文件
- `.temp/archive/` 已归档（带日期命名）
