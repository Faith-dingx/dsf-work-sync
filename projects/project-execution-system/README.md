# 项目全流程执行保障系统（Project Execution System）

> 系统目标：**从立项到验收的全流程，保障被严格执行**——把"语言"（规则/流程/纪律）全部"设备化"（机器强制），**不靠模型自觉**。
> 本质：这不是"写个代码"的项目，而是一套**保障系统**。

## 架构总览

```
项目全流程执行保障系统
├── 子系统1：能力路由（skill-router）—— 辅助模型判断该注入哪些 skill
├── 子系统2：双 Agent 协作 —— 代码 Agent（执行）+ 监督质检 Agent（把关）
├── 子系统3：质量门禁 —— husky（lint/type/test 硬卡）+ Semgrep（静态质检）
└── 子系统4：流程模板与规范 —— 全流程 P0-P5 + Superpowers 借鉴
```

## 核心哲学

**凡能用"设备"（机制）表达的，就不用"语言"（自觉）。**
语言靠模型理解、会遗忘、会违背；设备自动执行、绕不过、不靠自觉。
