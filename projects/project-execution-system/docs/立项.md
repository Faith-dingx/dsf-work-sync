# 系统立项：项目全流程执行保障系统

> 日期：2026-08-19 | 状态：立项（系统项目，非单点代码项目）

---

## 一、背景与问题

模型做代码工作时的高频顽疾：丢三落四 / 大文件检索修改难 / 进死胡同不自知 / 陷细节忽略全局。
根源：**现有规则、skill、流程文档都是"语言"**——靠模型理解 + 自觉执行，会遗忘、会违背、会漏用。

## 二、系统目标

**从立项到验收的项目全流程，保障被严格执行**——把"语言"（规则/流程/纪律）全部"设备化"（机器强制、每轮注入、独立监督），使流程执行**不依赖模型自觉**。

## 三、范围

**做**（4 个子系统 + 整合）：

1. **能力路由**（skill-router）：辅助模型（9888）判断该注入哪些 skill，主模型只看到被选中的。
2. **双 Agent 协作**：代码 Agent（专注执行）+ 监督质检 Agent（独立盯流程/查遗漏/防死胡同）。
3. **质量门禁**：husky（lint/type/test 硬卡）+ Semgrep（外部调用静态质检）。
4. **流程模板与规范**：全流程 P0-P5 定义 + Superpowers 流程借鉴（查缺补漏）。

**不做**：

- 模型升级策略（用户自行管理）。
- 飞书/浏览器自动化（后续项目）。
- 具体业务代码项目（本系统是保障其他项目执行的框架）。

## 四、核心设计

### 4.1 全流程（P0-P5，含 Superpowers 借鉴）

| 阶段        | 产出                                                                     | 门禁              |
| ----------- | ------------------------------------------------------------------------ | ----------------- |
| P0 立项     | brainstorming（发散）→ grill-me（拷问）→ 立项文档 → 用户确认             | 无立项文档不进 P1 |
| P1 规划     | 计划文档（文件结构先定 + bite-sized 任务 + 每任务验收）→ 用户确认        | 未确认不进 P2     |
| P2 实施     | TDD + 小步（一次 1 任务）+ 每步验证绿 + worktrees 隔离                   | husky 硬卡        |
| P3 验证评审 | verification 铁律（证据先于断言）+ self-review → 外部评审 + Semgrep 质检 | 清单全过才进 P4   |
| P4 验收部署 | 分支整合决策 + 部署 + 用户验收                                           | 验收不过不交付    |
| P5 收尾沉淀 | CHANGELOG/PROGRESS + project-checklist 复核                              | 记录未完成不算完  |

### 4.2 三层保障机制（执行保障核心）

1. **机器门禁**：husky / 测试 / 阶段检查脚本 —— 不通过报错，绕不过。
2. **系统注入**：记忆规则 / todo / goal —— 每轮强制可见，逃不掉。
3. **独立监督**：监督质检 Agent / 阶段检查点 / subagent 评审 —— 不靠主代理自觉。

### 4.3 "语言→设备"哲学

凡能用机制（设备）表达的，就不用自觉（语言）。规则/skill 的"语言"逐条翻译成"设备"：

- "必须用 skill" → skill-router（自动路由）
- "验证后才能声称完成" → verification 铁律 + 门禁
- "别死胡同" → goal 熔断 + 监督
- "别丢三落四" → 验收清单核对 + 监督 Agent

### 4.4 Superpowers 借鉴点（已并入全流程）

brainstorming（立项前发散）/ verification 铁律（证据先于断言）/ self-code-review（先自查再外审）/ 文件结构先定 / bite-sized 任务 / worktrees 隔离 / project-checklist。

## 五、验收标准

1. 聊计划/文档时，不会被注入代码 skill（能力路由隔离生效）。
2. 做代码时，相关辅助（lsp/语义搜索/TDD/评审）自动可用。
3. 监督质检 Agent 能发现死胡同 / 遗漏 / 全局偏差，并反馈闭环。
4. 门禁硬卡生效：不合格的提交/推送被机器拦截。
5. 全流程 P0-P5 端到端可跑（用真实项目验证一次）。
6. 流程执行不依赖模型自觉（机制自动兜底）。
