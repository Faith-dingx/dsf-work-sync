# Agent 能力路由与双 Agent 协作体系（子系统 1+2）

> **定位更新**：本立项已并入系统项目「项目全流程执行保障系统」（/projects/project-execution-system/），作为其**子系统 1（能力路由）+ 子系统 2（双 Agent）**的详细设计。

> 项目目标：解决模型做代码工作时的 4 大顽疾（丢三落四 / 大文件检索修改难 / 进死胡同不自知 / 陷细节忽略全局），通过**辅助模型路由 skill 注入** + **代码 Agent / 监督质检 Agent 分工协作**，把保障从"模型自觉"变成"机制自动"。

## 入口

- 立项与初步计划 → `docs/立项与初步计划.md`
- 进展记录 → `docs/进展.md`（实施阶段建立）

## 核心思路

1. **skill-router**：用辅助模型（9888 免费）判断"当前任务该注入哪些 skill"——主模型只看到被选中的，从源头隔离无关 skill（如聊计划时不会被塞代码 skill）。
2. **代码 Agent**：专注代码执行（lsp + 语义搜索 + TDD + 代码 skill）。
3. **监督质检 Agent**：独立监督执行（死胡同 / 丢三落四 / 全局视角 / 质检），不"当局者迷"。
