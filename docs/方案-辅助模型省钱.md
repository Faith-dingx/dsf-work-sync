## 〇、已查实的关键事实（不再重复查）

| 项 | 结论 |
|---|---|
| **prompt caching** | DeepSeek 的 KV cache **自动生效**（dsh 适配器已报告 `cacheReadTokens`），同一前缀自动命中按 ~10% 价计费。**无需任何配置。** |
| **agnes-2.5-flash** | **免费，实测可用**（9888 网关记账确认压缩调用 in=180648/out=1814 成功）。经 router-9888 软路由网关调用（不再直连 AGNES_API_KEY）。 |

| **会话标题** | dsh 有 `session-title` 服务但 full 预设**未挂载**，挂载+配 agnes 即可。 |
| **检索** | sessionQuery 纯 FTS 零成本，**已省钱**，无需改。 |
